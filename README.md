<p>
                                                                                   🐦 Bird Garden | باغ پرندگان

به پروژه **Bird Garden** خوش آمدید! 🌿🦜

این پروژه یک وبسایت معرفی برای **باغ پرندگان** است که با هدف نمایش فضای مجموعه، معرفی پرندگان و ایجاد یک ظاهر جذاب و طبیعت‌محور طراحی شده است.

## 🌿 درباره پروژه

وبسایت باغ پرندگان یک صفحه معرفی با طراحی ساده و چشم‌نواز است که بخش‌های مختلفی برای معرفی مجموعه، نمایش تصاویر پرندگان و ارائه اطلاعات مربوط به باغ دارد.

تمرکز اصلی پروژه روی طراحی ظاهری، ترکیب‌بندی مناسب عناصر و ایجاد یک فضای هماهنگ با موضوع طبیعت و پرندگان بوده است.

## ✨ ویژگی‌های وبسایت

* 🐦 معرفی باغ پرندگان
* 🦜 نمایش تصاویر و معرفی پرندگان
* 🌿 طراحی با حال‌وهوای طبیعت و فضای سبز
* 🖼️ استفاده از تصاویر جذاب
* 🎨 رابط کاربری زیبا و چشم‌نواز
* 🧭 منوی ساده و کاربردی
* 📍 بخش معرفی و اطلاعات مجموعه
* 📸 بخش نمایش تصاویر

## 🛠️ تکنولوژی‌های استفاده‌شده

* **HTML5** — ساختار و محتوای صفحات
* **CSS3** — طراحی، استایل‌دهی و ایجاد ظاهر وبسایت

## 📱 وضعیت پروژه

> ⚠️ این پروژه **Responsive نیست** و برای نمایش در اندازه مشخصی از صفحه طراحی شده است.

## 🎯 هدف پروژه

هدف از ساخت این پروژه، تمرین طراحی صفحات وب با HTML و CSS و ایجاد یک وبسایت معرفی با موضوع طبیعت و پرندگان بوده است.

در این پروژه تلاش شده با استفاده از طراحی بصری مناسب، تصاویر مرتبط و چیدمان منظم، یک تجربه ساده و جذاب برای بازدیدکننده ایجاد شود.

## 🚀 نحوه اجرا
